## Quick Fix Patterns
- Ambiguity → Add audience, objective, constraints, success criteria. → [Clarity criteria](../08-diagnostics/clarity-criteria.md)
- Missing context → Provide source, scope, examples, and assumptions. → [Context checklists](../08-diagnostics/context-checklists.md)
- Unstructured output → Specify Markdown/JSON schema and validation rules. → [Markdown layouts](../09-response-formats/markdown-layouts.md) | [JSON specs](../09-response-formats/json-specs.md)
- Hallucination risk → Require citations, enable verification steps, and limit scope. → [Self-critique](../04-techniques-library/self-critique.md) | [Verification blocks](../09-response-formats/verification-blocks.md)
