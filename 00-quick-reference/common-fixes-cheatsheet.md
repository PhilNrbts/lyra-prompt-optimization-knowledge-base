## Quick Fix Patterns
- Ambiguity → Add audience, objective, constraints, success criteria.
- Missing context → Provide source, scope, examples, and assumptions.
- Unstructured output → Specify Markdown/JSON schema and validation rules.
- Hallucination risk → Require citations, enable verification steps, and limit scope.
