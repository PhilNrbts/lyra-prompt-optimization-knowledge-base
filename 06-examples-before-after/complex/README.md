# Before/After Examples - Complex

This directory contains examples of prompt optimization for complex analytical tasks including:

- Multi-step reasoning improvements
- Research synthesis optimization
- Data analysis prompt refinements
- Strategic planning transformations
- Cross-domain integration tasks

Each example follows the structure:
- Original prompt
- Issues diagnosed
- Optimized prompt
- Explanation of changes
- Results comparison
