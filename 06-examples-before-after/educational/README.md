# Before/After Examples - Educational

This directory contains examples of prompt optimization for educational tasks including:

- Learning objective alignment
- Assessment generation improvements
- Curriculum design optimization
- Scaffolding technique refinements
- Educational content creation

Each example follows the structure:
- Original prompt
- Issues diagnosed
- Optimized prompt
- Explanation of changes
- Results comparison
