# Before/After Examples - Meta-Prompting

This directory contains examples of using prompts to optimize other prompts including:

- Prompt critique and improvement workflows
- Automated prompt enhancement techniques
- Meta-optimization strategies
- Self-improving prompt systems
- Recursive optimization examples

Each example follows the structure:
- Original prompt
- Issues diagnosed
- Optimized prompt
- Explanation of changes
- Results comparison
