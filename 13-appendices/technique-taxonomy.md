## Taxonomy Structure

### Core Techniques
- In-Context Learning (Zero-shot, Few-shot, Example Selection)
- Thought Generation (Chain-of-Thought, Step-Back, Thread-of-Thought)
- Decomposition (Least-to-Most, Tree-of-Thought, Plan-and-Solve)
- Ensembling (Self-Consistency, Vote-K, Meta-CoT)
- Self-Criticism (Self-Refine, Verification, Calibration)

### Implementation Methods
- Manual (Trial-Error, Iterative Refinement)
- Automated (Meta-Prompting, Evolutionary, Gradient-Based)
- Hybrid (Human-AI Loop, Assisted Optimization)
