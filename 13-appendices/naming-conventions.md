## Directory Naming
- Use numbered prefixes for ordered sections: `00-quick-reference/`
- Use lowercase with hyphens for separation: `platform-nuances/`
- Group related content logically under domain folders

## File Naming
- Use lowercase with hyphens: `chain-of-thought.md`
- Be descriptive but concise: `platform-selection-tree.md`
- Use `.md` extension for all Markdown files
- Include version in filename for snapshots: `v1.0.0-techniques.md`

## Metadata Consistency
- Maintain consistent field names across all documents
- Use standardized vocabulary for tags and classifications
- Include all required fields in YAML front-matter
