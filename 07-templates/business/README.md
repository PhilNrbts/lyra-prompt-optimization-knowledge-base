# Templates - Business

This directory contains prompt templates for business tasks including:

- Business proposal frameworks
- Strategic planning templates
- Meeting agenda structures
- Project brief templates
- Stakeholder communication guides
- Decision-making frameworks
- Performance review templates

Each template includes:
- YAML front-matter with metadata
- Template structure and variables
- Usage examples and guidelines
- Platform-specific adaptations
- Success metrics and validation
